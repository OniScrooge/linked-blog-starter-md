# Facts
- __RAM__ - Random access memory
	- _DRAM_ - Dynamic, consists of capacitors that slowly leak charge over time, thus they must refresh every few milliseconds to prevent data loss. Very cheap
	- _SRAM / RAM_ Static, consists of circuits similar to the D flip-flop, doesn't need to be refreshed and builds [[cache memory]], very fast
- __ROM__ - Read-only memory, doesn't need to be refreshed. Semi permanent, data persists even while system is off.
- Hierarchy:
	- Small, fast storage elements are kept in the CPU
	- Larger, (almost) permanent storage in the form of disk and tape drives
