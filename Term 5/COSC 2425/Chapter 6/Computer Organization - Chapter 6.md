# Formulas
- __Average memory access time__ - $t_{avg}=h*t_{c}+(1-h)*t_{m}$ Where _h_ is the hit rate, $t_{c}$ is the cache access time, and $t_{m}$ is the main memory access time.
- __Offset bits__ - $\log_{2}(b)=n$ Where _b_ is the number of bytes per block, and n is the number of bits in the offset.
- __Index bits__ - $\log_{2}(b)=n$ Where _b_ is the number of blocks in the cache
- __Tag size__ - $T-(o+i)=n$ Where _T_ is the total address size, _o_ is the offset, _i_ is the index, and _n_ is the number of bits in the tag.
- __Mapping__:
	- Get the _offset_, _index_, and _tag_.
		- Ex) 3, 3, 2
	- Break down the address into binary
		- Ex) $0x1F=00011111$
	- Associate the bits with the address
		- Ex) First 3 to the _offset_ `000`, next 3 to the _index_ `111`, and 2 more to the _tag_ `11`
	- _Index_ is the address of the cache set, so break it into a numerical value
		- Ex) `111` =` 7`, so the address `0x1F` maps to cache block `7`
- __Blocks of Main Memory__ - $N_{b}=\frac{S_{mm}}{S_{b}}$ Where $N_{b}$ is the number of blocks, $S_{mm}$ is the size of main memory, and $S_{b}$ is the size of each block.
- __Pages in Virtual Memory__ - $P=\frac{S_{vm}}{S_{p}}$ Where $S_{vm}$ is the total virtual memory size, and $S_{p}$ is the page size.
- __Page Frames of Physical Memory__ - $F=\frac{S_{pm}}{S_{p}}$ Where the $S_{pm}$ is the size of physical memory,  and $S_{p}$ is the page size.

# Facts
- Direct mapping is set associative mapping with a set size of 1
- Memory segmentation - external fragmentation
- Paging - internal fragmentation
- The offset field of a main memory address is used to determine the location of the desired data in the cache block.
- Caching __DOES NOT__ break down when programs exhibit good locality
- Cache mapping is necessary because the address generated by the CPU must be converted to a cache location.
- It is important to know if a computer is byte or word addressable because we need to know how many addresses are contained in main memory, cache, and in each block when doing cache mapping.
- When a computer uses paging, there must be a page table for every process.
- Cache memory is effective because of the principle of locality.
- _Cache replacement algorithms_:
	- LRU (Least Recently Used)
	- FIFO (First In, First Out)
	- Random
- A major advantage of direct mapped cache is its simplicity and ease of implementation. The main disadvantage of direct mapped cache is its performance is degraded if two or more blocks that map to the same location are used alternately.
- A unified cache is a cache that holds both data and instructions.

# Summary
- __RAM__ - Random access memory, allows data to be both read from and written to easily and rapidly.
	- _DRAM_ - Dynamic, consists of capacitors that slowly leak charge over time, thus they must refresh every few milliseconds to prevent data loss. Very cheap
	- _SRAM / RAM_ Static, consists of circuits similar to the D flip-flop, doesn't need to be refreshed and builds [[cache memory]], very fast
- __ROM__ - Read-only memory, doesn't need to be refreshed. Semi permanent, data persists even while system is off.
- Hierarchy:
	- Small, fast storage elements are kept in the CPU
	- Larger, (almost) permanent storage in the form of disk and tape drives
